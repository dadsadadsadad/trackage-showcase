Questions it answers

Each one is a click away, for one agent or all of them, for today or the whole year.

Which project cost the most this month?Filter everything to one project, agent or computer.
Is my Claude Max plan worth $100?What your usage would cost at API prices, plan by plan.
Why did that one session cost $9?Context growth call by call, every tool result and when it compacted.
Would a cheaper model have done it?Your exact token mix priced on twelve models.
Which tools keep failing?Failure rate per tool, MCP server and shell command.
How close am I to my rate limit?Codex windows and Claude 5-hour blocks, with when they reset.
Does my invoice match what I used?Anthropic and OpenAI’s daily charges next to what Trackage counted.
What is the whole team spending?Spend by person, project, agent and model, with a shared monthly budget.

What leaves your computer

The collector builds each upload field by field from an allow-list and checks it before sending. The server checks it again and rejects anything with text in it.

Sent

  • Token counts and timings
  • Model and tool names, success or failure
  • Context size, compactions, lines added and removed
  • A project label you choose, a hash, or nothing

Never sent

  • Prompts, replies and session titles
  • Code, diffs and file contents
  • Tool inputs and outputs, command arguments
  • Paths, file names, branch names, secrets

trackage sync --dry-run prints the exact payload and sends nothing. The collector is open source under the MIT license.
