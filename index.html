Privacy and safety

Your data never leaves your PC.

There's no account and no cloud. AI Manager reads files your agents already wrote and shows them to you, and that's all.

What it does

  • Reads Claude Code and Codex session logs, without changing them
  • Saves its own settings in a folder in your user profile
  • Shows the dashboard only to this computer (127.0.0.1)
  • Blocks other websites from reading or changing its data

What it never does

  • Upload your prompts, code or usage anywhere
  • Use analytics, ads or tracking
  • Ask for admin rights or install background services
  • Start with Windows unless you turn that on

FAQ

Questions

Is it safe to install?

Yes. It only reads your agents' log files and writes its own settings. Every release is scanned with Microsoft Defender before it's published, it installs for your user only without asking for admin rights, and it uninstalls cleanly from Windows Settings.

Why does Windows say "Windows protected your PC"?

That's SmartScreen, which warns about apps that aren't code-signed yet or are new and not yet widely downloaded. It isn't a virus warning. Click More info, then Run anyway.

Do I need to connect my Claude or OpenAI account?

No. Claude Code and Codex already save session logs on your computer, and AI Manager reads those. Nothing to log into.

What does "cost" mean if I'm on a subscription?

It's what the tokens would cost at API list prices. You aren't billed that on a Claude or ChatGPT plan, but it's the clearest way to compare how heavy different work was.

Does it work on macOS or Linux?

Windows builds are available now. macOS and Linux builds are set up and will be published with upcoming releases.
